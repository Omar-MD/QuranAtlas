How multi-tag is handled:
1. Pinned "Selected" strip at the top of the tag region — always visible, never scrolls away. Shows count badge, a "Clear all" link, and each chip with an inline × for one-tap removal.
2. "All tags" region below shows the unselected tags only (selected ones are hoisted up). No duplication, no confusion about what's active. Ordered by "most used first" — so familiar vocabulary comes first.
3. Search field shows a live tag count ("16 tags" → "3 matches") and filters the grid in place. The "+ create" chip appears only when the search term has no exact match.
4. When the list is long, the sheet body scrolls, but the header (verse quote + selected strip) and footer (actions) stay pinned — so Save/Cancel are always reachable regardless of how many tags are scrolled through.
5. Dim state for unselected chips when 7+ are selected — visual priority stays on what's already applied.
6. Empty selection shows a gentle prompt ("No tags yet — pick one below or search") instead of an empty strip — so the UI still reads as structured even at zero.
