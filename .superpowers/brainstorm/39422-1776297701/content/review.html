Empty state
Design moves unique to Review:
1. Segmented pill replaces the 3 dropdowns (Group / Sort / Filter). Tag / Surah / All is always one tap. Sort becomes a small pill on the right.
2. Filter chips with color dots — tag filters show their semantic color (mercy = coral, gratitude = amber, patience = blue, reflection = purple, prayer = green). One consistent palette across the whole app.
3. Mark card mirrors the reader verse block — verse reference label → Arabic → English → (note) → tag chips. Same visual grammar, so marks feel like clipped verses, not list items.
4. Group headers are minimal — just name + count under a hairline. No heavy section cards.
5. Notes get a left bar in the accent color — visually distinct from the verse itself, reads as "your voice."
6. Empty state is warm, not a shrug — explains the primary action and CTAs straight into Read.
