# Agentic UI Refactor 04 - Stale Selector And Token Cleanup Implementation Spec

> **For sequential agents:** Start only after Spec 03 is committed. This spec
> turns advisory style-health reports into clean blocking checks.

## Goal

Remove verified-dead CSS, quarantine unavoidable legacy selectors, fix or
justify primitive-token and hardcoded-design-value warnings, and promote
advisory checks to blocking.

## Depends On

- Spec 03 complete and committed.
- `pnpm run check` passes at the start.
- Selector, primitive-token, and design-literal advisory scripts exist and run
  during `pnpm run check`.
- Component ownership is clear enough to assign warnings to owners.

## Produces

- No unreviewed selector-liveness warnings.
- No unreviewed primitive-token consumption warnings.
- No unreviewed hardcoded-design-value warnings.
- Explicit allowlists with owner, reason, category, and removal condition.
- Advisory checks promoted to blocking.
- `docs/tech-stack.md` updated to reflect blocking status.

## Non-Goals

- Do not redesign components to satisfy checks.
- Do not rename multiple unrelated component families in one edit.
- Do not remove removed-scope implementation if tests still rely on it for
  regression containment. Quarantine and document instead.
- Do not weaken check scripts to make the repo pass.

## Required Reads

- Output from:
  - `node scripts/check-selector-liveness.mjs --advisory`
  - `node scripts/check-primitive-token-consumption.mjs --advisory`
  - `node scripts/check-design-literals.mjs --advisory`
- All CSS partials under `src/styles/patterns/**` and
  `src/styles/surfaces/**`
- Svelte, TS, and JS files referenced by the reports
- `docs/context/surfaces/read.md`
- `docs/context/surfaces/navigate.md`
- `docs/context/surfaces/configure.md`
- `docs/context/surfaces/onboard.md`
- `docs/context/surfaces/infra.md`
- `docs/context/surfaces/mark.md`, `review.md`, and `listen.md` only when a
  warning points to removed-scope implementation

## Work Requirements

### 1. Save Advisory Reports

Run:

```bash
mkdir -p .scratch/agentic-ui-refactor
node scripts/check-selector-liveness.mjs --advisory > .scratch/agentic-ui-refactor/04-selector-liveness-before.txt
node scripts/check-primitive-token-consumption.mjs --advisory > .scratch/agentic-ui-refactor/04-primitive-token-before.txt
node scripts/check-design-literals.mjs --advisory > .scratch/agentic-ui-refactor/04-design-literals-before.txt
```

Do not stage `.scratch/**`.

### 2. Selector Liveness Triage

For every warning, assign one result:

- remove verified-dead CSS and update tests/docs if they referenced it;
- add a code reference when the class is legitimately styled but the scanner
  missed it;
- add a precise allowlist entry for a real dynamic or external case;
- quarantine legacy removed-scope selectors in a clearly named file if removal
  is unsafe in this branch.

Allowlist entries must include:

```js
{
  pattern: 'qa-example-*',
  owner: 'read',
  category: 'dynamic-class',
  reason: 'Generated by ... and exercised by ...',
  removeWhen: 'Replace imperative DOM builder with Svelte class directive'
}
```

Class renames are allowed only one component family at a time. Each rename must
update component code, CSS, tests, docs, and visual proof in the same change.

### 3. Primitive Token Consumption

For every primitive token warning outside `src/styles/tokens/**`:

- replace with an existing semantic `--qa-*` token when one matches intent;
- add a new semantic token in `src/styles/tokens/semantic.css` only when the
  design role is real and reusable;
- allowlist temporary compatibility aliases only with owner and removal
  condition.

Do not replace layout dimensions simply because they are literal. This cleanup
targets primitive design tokens consumed outside the token layer.

### 4. Hardcoded Design Values

For every hardcoded color, raw motion literal, or raw radius warning:

- replace with a semantic token when the value is a design decision;
- keep local geometry literals when they are layout mechanics, not design
  tokens;
- allow intentional swatches, generated preview palettes, SVG/browser quirks,
  and one-off geometry only with a local comment or explicit allowlist entry.

Local comments must be short and explain the reason, not the history.

### 5. Promote Checks To Blocking

Once reports are clean or allowlisted, update `package.json`:

- remove `--advisory` from `check-selector-liveness.mjs`;
- remove `--advisory` from `check-primitive-token-consumption.mjs`;
- remove `--advisory` from `check-design-literals.mjs`.

Update `docs/tech-stack.md` so the scripts are documented as blocking static
checks inside `pnpm run check`.

## Verification

Run final reports:

```bash
node scripts/check-selector-liveness.mjs > .scratch/agentic-ui-refactor/04-selector-liveness-after.txt
node scripts/check-primitive-token-consumption.mjs > .scratch/agentic-ui-refactor/04-primitive-token-after.txt
node scripts/check-design-literals.mjs > .scratch/agentic-ui-refactor/04-design-literals-after.txt
```

Run targeted unit/e2e tests for any touched component. Then run:

```bash
pnpm run check
pnpm run docs:check
git diff --check
```

## Acceptance Criteria

- All three formerly advisory scripts are blocking in `pnpm run check`.
- No unreviewed warnings remain.
- All allowlist entries include owner, category, reason, and removal condition.
- Removed selectors are proven unused by code search and liveness output.
- Token and design literal fixes preserve current visual direction.
- Verification commands pass.

## Commit

Suggested message:

```bash
git commit -m "chore(ui): promote style health checks"
```

- that style-health checks are now blocking;
