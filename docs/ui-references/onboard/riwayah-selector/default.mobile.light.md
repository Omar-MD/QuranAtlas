# Riwayah Selector - Default - Mobile Light

## Component

Riwayah selector on onboarding screen 3.

## State and viewport

Default onboarding selector state at mobile portrait width in the light theme, with Qaloon selected.

## Accepted visual traits

The selected card should read clearly, unavailable rows should remain legible, and the selector should feel like part of the onboarding stack rather than a separate settings sheet.

## Forbidden traits

No giant selection cards, no decorative calligraphy treatment, no ambiguous disabled state, and no clipped copy inside rows.

## Token expectations

Use semantic onboarding surface, border, accent, muted text, and disabled-state tokens.

## Responsive differences

Tablet and desktop can widen the selector, but the same card hierarchy and disabled-state clarity should remain.

## Non-goals

This reference does not define the theme picker or translation selector screens.
