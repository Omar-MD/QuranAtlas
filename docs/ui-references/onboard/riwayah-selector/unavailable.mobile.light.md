# Riwayah Selector - Unavailable - Mobile Light

## Component

Unavailable Riwayah option card on onboarding screen 3.

## State and viewport

Disabled Riwayah card at mobile portrait width in the light theme.

## Accepted visual traits

Unavailable state should be obvious through tone, contrast, and copy, while still remaining readable and consistent with the enabled card family.

## Forbidden traits

No hidden disabled reason, no washed-out unreadable text, and no active-style affordance on unavailable rows.

## Token expectations

Use semantic disabled, muted text, border, and onboarding surface tokens.

## Responsive differences

Larger viewports may widen the row, but the disabled-state clarity should remain unchanged.

## Non-goals

This reference does not define installation flows or later settings-based Riwayah activation.
