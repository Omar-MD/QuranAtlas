# Verse Row - Tafsir Open - Mobile Light

## Component

Verse row with inline tafsir preview expanded.

## State and viewport

Active verse row on `#/s/1` after the inline tafsir preview opens at mobile portrait width in the light theme.

## Accepted visual traits

The active accent rail, tafsir badge, preview body, and verse content should read as one stack with clear hierarchy and no overflow.

## Forbidden traits

No modal framing inside the row, no clipped preview controls, no broken spacing between verse text and preview, and no color-only active signal.

## Token expectations

Use semantic accent, raised-surface, border, text, and focus tokens for the active row and preview controls.

## Responsive differences

Larger viewports may widen the preview, but the inline stacked relationship between verse and tafsir should remain intact.

## Non-goals

This reference does not define the full tafsir sheet or footnote popover behavior.
