# Verse Row - Default - Mobile Light

## Component

Verse row on the reader surface.

## State and viewport

Default collapsed verse row on `#/s/1` at mobile portrait width in the light theme.

## Accepted visual traits

Reader-first spacing, strong Arabic hierarchy, quiet translation support, compact verse number control, and no surrounding card chrome.

## Forbidden traits

No nested cards, no decorative gradients, no oversized pills, no dashboard framing, and no detached translation block.

## Token expectations

Use semantic reader spacing, text, border, focus, and accent tokens only.

## Responsive differences

Tablet and desktop may widen gutters and text measure, but the row should keep the same unframed reading hierarchy.

## Non-goals

This reference does not define the open tafsir state or desktop-only layout behavior.
