# Margin Header - Verse - Mobile Light

## Component

Mobile reader margin header on the verse route.

## State and viewport

Visible header on `#/s/1` at mobile portrait width in the light theme.

## Accepted visual traits

Single-row layout, balanced left and right controls, centered surah label, and compact vertical height with no second navigation row.

## Forbidden traits

No stacked tabs, no oversized header bar, no decorative badges, and no control overlap with the label.

## Token expectations

Use semantic header surface, border, icon, text, and touch-target tokens.

## Responsive differences

Tablet can breathe slightly more, but the same single-row hierarchy should hold below the desktop rail breakpoint.

## Non-goals

This reference does not define the hidden-on-scroll state.
