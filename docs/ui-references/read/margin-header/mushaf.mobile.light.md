# Margin Header - Mushaf - Mobile Light

## Component

Mobile reader margin header on the Mushaf route.

## State and viewport

Visible header on `#/m/1` at mobile portrait width in the light theme.

## Accepted visual traits

Single-row layout with the page label centered, balanced nav/settings controls, and the same compact chrome rhythm as the verse route.

## Forbidden traits

No second row, no card treatment, no label clipping, and no route-specific chrome that breaks the shared header family.

## Token expectations

Use the shared margin-header semantic surface, border, icon, text, and spacing tokens.

## Responsive differences

Tablet can widen spacing slightly, but the shared header structure remains the same below desktop.

## Non-goals

This reference does not define the page controls drawer state.
