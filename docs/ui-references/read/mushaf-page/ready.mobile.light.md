# Mushaf Page - Ready - Mobile Light

## Component

Rendered Mushaf page figure on the reader surface.

## State and viewport

Ready Mushaf page on `#/m/1` at mobile portrait width in the light theme.

## Accepted visual traits

The page should feel unframed, centered, and calm, with the SVG page carrying the visual weight rather than extra container chrome.

## Forbidden traits

No decorative frame, no card shadow around the page, no clipped page edge, and no extra route-level panel treatment.

## Token expectations

Use semantic app-surface, page-spacing, and control tokens only; the page presentation should not rely on hardcoded framing values.

## Responsive differences

Mobile favors fit-width reading while larger viewports may expose more surrounding space or alternate fitting behavior.

## Non-goals

This reference does not define the page controls dock or tablet fit-page behavior.
