# Mushaf Page - Ready - Tablet Portrait Light

## Component

Rendered Mushaf page figure on the reader surface.

## State and viewport

Ready Mushaf page on `#/m/1` at tablet portrait width in the light theme.

## Accepted visual traits

The page should stay unframed, centered, and comfortably scaled for portrait tablet reading without feeling like a modal or card.

## Forbidden traits

No decorative border frame, no inset card stack, no clipped page, and no desktop-style chrome crowding the reading area.

## Token expectations

Use the same semantic page, spacing, and surface tokens as mobile, with scaling driven by existing layout rules rather than bespoke literals.

## Responsive differences

Tablet portrait can show more surrounding breathing room than mobile while keeping the page anchored and visually primary.

## Non-goals

This reference does not define landscape tablet or desktop Mushaf layout.
