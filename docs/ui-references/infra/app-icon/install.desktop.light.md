## Component

App installed icon.

## State and viewport

Installed app icon, desktop light-theme reference.

## Accepted visual traits

Islamic mosaic and calligraphy-inspired Latin Q, strong teal/gold contrast, clear single-letter silhouette, sharp border geometry.

## Forbidden traits

No book metaphor, no Arabic text, no numbered edge marks, no black-dominant field.

## Token expectations

Use QuranAtlas teal, gold, ivory, and a small turquoise accent. Keep the field lighter than black while preserving strong contrast against the Q.

## Responsive differences

The icon must remain legible at favicon and home-screen sizes; fine mosaic detail may simplify in raster exports.

## Non-goals

This reference does not define in-app nav drawer logo details or marketing artwork.
