Component: Verse Settings row controls
State and viewport: Mobile-width Verse-mode row stack.

Accepted visual traits: rows use one compact ledger grammar with consistent labels, values, chevrons, toggles, segmented controls, status text, and 44px touch targets. The exact control inventory is: Font Size, Reading Flow, Active Riwayah, Quran Text Style, Translation Source, Show Translation, Tafsir Source, and Manage Assets.

Forbidden traits: no duplicate Active Riwayah row, no Mushaf Edition row, no invented controls, no random labels, no excessive icons, no nested cards, and no search fast-navigation row.

Token expectations: use semantic tokens for row surfaces, dividers, text, active bronze actions, disabled reasons, focus rings, and touch sizing.

Responsive differences: mobile stacks rows vertically. Tablet and desktop may widen values/actions but must preserve the same inventory and row grammar.

Non-goals: this reference does not define picker contents, install logic, or exact storage byte values.
