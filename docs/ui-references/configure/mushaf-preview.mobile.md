Component: Mushaf Settings live preview
State and viewport: Mobile-width preview module inside Mushaf Settings.

Accepted visual traits: the preview is compact enough to leave room for settings rows on a phone. It shows page, riwayah, and edition context, then an unframed Mushaf page crop as the primary content. It shares the Verse preview's calm parchment grammar while remaining mode-specific.

Forbidden traits: no Verse typography controls, no translation line, no framed or shadowed page card, no decorative icon cluster, no fake calligraphy ornament, and no preview that consumes the whole mobile screen.

Token expectations: use Mushaf ground/ink/accent tokens, QuranAtlas surface/border tokens, and real sanitized Mushaf rendering in implementation. Generated Arabic text is not source content or rendering proof.

Responsive differences: mobile height should stay roughly preview-band sized so rows remain visible. Tablet/desktop can widen but must remain unframed.

Non-goals: this reference does not define exact SVG output, page navigation controls, or final edition metadata copy.
