# Theme Night Controls - Default - Mobile Light

## Component

Theme and night-mode control group in settings.

## State and viewport

Default control group inside verse settings at mobile portrait width in the light theme.

## Accepted visual traits

Theme swatches and night-mode choices should feel like one coordinated control area, with clear active state, compact density, and readable labels.

## Forbidden traits

No card-in-card presentation, no ambiguous active state, no clipped labels, and no decorative color treatment beyond the semantic theme cues.

## Token expectations

Use semantic control, accent, border, text, and focus tokens only.

## Responsive differences

Tablet and desktop may allow more horizontal breathing room, but the grouping and active-state hierarchy should stay the same.

## Non-goals

This reference does not define the rest of the settings footer or auto-theme runtime behavior.
