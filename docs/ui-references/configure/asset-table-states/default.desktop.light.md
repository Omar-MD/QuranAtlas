# Asset Table States - Default - Desktop Light

## Component

Desktop asset table section.

## State and viewport

Desktop-width asset table on `#/assets` in the light theme.

## Accepted visual traits

Rows should stay dense, readable, and operational, with status and action affordances visible without relying on color alone.

## Forbidden traits

No card stack inside the table area, no oversized row height, no ambiguous disabled actions, and no hidden compatibility reasons.

## Token expectations

Use semantic table divider, text, accent, warning, error, disabled, and focus tokens.

## Responsive differences

Desktop favors tabular scanning. Mobile may collapse the same information into stacked rows instead of columns.

## Non-goals

This reference does not define exact column widths or every install-progress variant.
