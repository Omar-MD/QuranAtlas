# Asset Status Live Region - Default - Mobile Light

## Component

Route-level asset status live region.

## State and viewport

Status line on `#/assets` at mobile portrait width in the light theme.

## Accepted visual traits

Compact status treatment, clear readable text, and enough prominence to announce state without visually dominating the route.

## Forbidden traits

No oversized alert banner, no color-only meaning, no hidden progress or error context, and no unrelated action clutter.

## Token expectations

Use semantic status, text, border, and focus tokens appropriate to the route-level announcer.

## Responsive differences

Desktop may reposition the same announcer near the header or toolbar while keeping the same information hierarchy.

## Non-goals

This reference does not define every possible network or storage message variant.
