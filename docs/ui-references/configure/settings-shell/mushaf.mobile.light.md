# Settings Shell - Mushaf - Mobile Light

## Component

Settings shell with the Mushaf-settings body.

## State and viewport

Open settings dialog on `#/m/1` at mobile portrait width in the light theme.

## Accepted visual traits

The shell should preserve the same structure as verse settings while accommodating Mushaf-specific controls without crowding or visual drift.

## Forbidden traits

No separate Mushaf-only shell chrome, no cramped picker rows, and no footer that feels detached from the dialog body.

## Token expectations

Use the shared settings-shell semantic tokens and row grammar so verse and Mushaf settings feel like one family.

## Responsive differences

Larger viewports may center or widen the shell, but the shared control density and footer grouping should remain intact.

## Non-goals

This reference does not define the reader page itself or asset-management route.
