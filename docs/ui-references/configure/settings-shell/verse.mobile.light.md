# Settings Shell - Verse - Mobile Light

## Component

Settings shell with the verse-settings body.

## State and viewport

Open settings dialog on `#/s/1` at mobile portrait width in the light theme.

## Accepted visual traits

One continuous sheet, strong top header, dense but breathable settings rows, and the footer controls integrated into the same surface rhythm.

## Forbidden traits

No nested cards inside the sheet, no floating footer slab, no clipped rows, and no oversized empty spacing.

## Token expectations

Use semantic sheet, border, text, row, focus, and accent tokens. Shared row grammar should remain visually consistent across picker, slider, and switch rows.

## Responsive differences

Tablet and desktop may widen or center the shell, but the row hierarchy and footer rhythm should remain consistent.

## Non-goals

This reference does not define the Mushaf-specific settings body or nested picker overlays.
