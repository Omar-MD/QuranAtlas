# React Settings Shell - Ledger - Desktop Light

## Component

React Settings shell.

## State and viewport

Default settings over the reader in a desktop right-side sidebar. The reference
also shows mobile treatment for responsive intent; implementation removes the
visible section numbers and the Mushaf Auto option per the accepted direction.

## Accepted visual traits

Dense operational settings ledger with clear labels, quiet metadata, and bronze
selected states. Verse-only controls stay in Verse mode, Mushaf-only controls
stay in Mushaf mode, and the reserved mode-control area prevents layout jumps.
Asset inventory reads as a compact table with the reference text/font, Mushaf,
and document icons, included status, and quiet chevrons on every row.
Appearance controls remain docked at the bottom as a split Theme and Night Mode
panel with square icon choices.

## Forbidden traits

No marketing hero treatment, decorative religious motifs, fake Quran text,
purple gradients, blobs, nested card stacks, visible section numbers,
optional-pack actions, or Mushaf Auto settings choice.

## Token expectations

Use existing React semantic tokens under `--qa-react-*` for surfaces, borders,
accents, focus, shadows, typography, radii, and transitions. Keep radii compact
and controls stable at the app touch target size.

## Responsive differences

Mobile stacks rows into a compact two-column index-and-control rhythm. Tablet
and desktop keep the right-side sheet shape with a wider ledger column.

## Non-goals

No source switching, install, verify, delete, sync, account, audio, tafsir,
import, export, or multiple-profile behavior.
