# Asset Management - Route - Mobile Light

## Component

Asset Management route assembly.

## State and viewport

Mobile portrait route at `#/assets` in the light theme.

## Accepted visual traits

Compact route header, active summary strip, route-level status line, and grouped asset sections that stay operational and scan-friendly in a single column.

## Forbidden traits

No marketing hero, no nested dashboard cards, no search-command chrome, and no oversized explanatory copy pushing the asset table offscreen.

## Token expectations

Use semantic app, raised row, border, accent, status, and focus tokens. State colors remain semantic rather than literal.

## Responsive differences

Mobile is a single scroll column. Tablet and desktop may expose more inline metadata or multi-column composition without changing the route identity.

## Non-goals

This assembly reference does not define every asset row state or exact copy for status messages.
