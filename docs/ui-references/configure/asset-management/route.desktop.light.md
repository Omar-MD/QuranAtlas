# Asset Management - Route - Desktop Light

## Component

Asset Management route assembly.

## State and viewport

Desktop route at `#/assets` in the light theme.

## Accepted visual traits

Dense operational layout, persistent navigation chrome outside the route, clear summary/header treatment, and grouped asset tables that favor scanning over decoration.

## Forbidden traits

No dashboard fluff, no oversized hero treatment, no app-version warning clutter, and no action styling that overuses accent color.

## Token expectations

Use semantic app, raised surface, border, accent, status, and focus tokens. Table density should come from existing design tokens and shared surface rules.

## Responsive differences

Desktop may show multi-column composition and wider tables; mobile remains a single-column assembly.

## Non-goals

This reference does not define every table-row state or tablet-specific composition.
