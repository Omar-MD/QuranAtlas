Component: Verse Settings live preview
State and viewport: Mobile-width preview module inside Verse Settings.

Accepted visual traits: the preview is compact enough to leave room for settings rows on a phone. It shows a Preview label, active riwayah/text-style chips, Arabic text as the primary content, and a translation line whose visibility can be reflected without changing the whole shell. It must feel like live reader content.

Forbidden traits: no full-screen preview takeover, no fake decorative calligraphy, no unrelated icons, no search/command affordance, no marketing hero, and no ornamental frame.

Token expectations: use reader typography tokens, QuranAtlas surface/border/accent tokens, and real theme variables. Generated Arabic text is not source content or rendering proof.

Responsive differences: mobile height should stay roughly preview-band sized so rows remain visible. Tablet/desktop can widen but should not become a decorative card.

Non-goals: this reference does not prescribe exact Quran copy, final line breaks, or picker internals.
