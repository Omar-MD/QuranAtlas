Component: Desktop Settings right sidebar
State and viewport: Desktop reader route with settings opened from AmbientDock/Settings.

Accepted visual traits: desktop settings open as a right-side sidebar/drawer, not a centered modal. Reader content remains visible to the left. The sidebar uses the same settings grammar as mobile: compact preview, ledger rows, Manage Assets action, and the shared Theme/Night controls.

Forbidden traits: no centered modal, no command/search entry, no marketing panel, no split hero layout, no nested generic cards, and no divergent desktop-only control language.

Token expectations: use QuranAtlas semantic tokens for sidebar surface, border/shadow, focus ring, reader backdrop/scrim if used, and bronze action states.

Responsive differences: desktop uses a fixed right sidebar around 400-460px. Mobile uses the full-screen shell reference. Tablet behavior must be proven before choosing full-height sheet or sidebar-style drawer.

Non-goals: this reference does not define exact sidebar width, animation mechanics, or all row content variants.
