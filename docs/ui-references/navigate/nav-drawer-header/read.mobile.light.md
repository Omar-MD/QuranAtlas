# Nav Drawer Header - Read - Mobile Light

## Component

Navigation drawer header for the read mode.

## State and viewport

Drawer open from `#/s/18` at mobile portrait width in the light theme, focused on the header cluster.

## Accepted visual traits

Reader-first product row, calm wordmark, clear about and close affordances, and a compact mode rail that feels integrated with the drawer rather than separate cards.

## Forbidden traits

No marketing hero, no oversized branding treatment, no double framing around controls, and no cramped close/about actions.

## Token expectations

Use semantic drawer surface, raised controls, border, text, and focus tokens.

## Responsive differences

Desktop navigation uses different chrome, so this reference is only authoritative below the desktop drawer breakpoint.

## Non-goals

This reference does not define the read-source lists or Wird card body.
