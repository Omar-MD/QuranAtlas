## Component

Daily Wird setup in the navigation drawer.

## State and viewport

No active Wird plan, mobile drawer, light theme.

## Accepted visual traits

Setup choices are grouped into clear sections with visible selected states, readable spacing, compact confirmation indicators, and restrained section icons.

## Forbidden traits

Do not create a separate full setup page, marketing hero, nested cards, or low-contrast selected states.

## Token expectations

Use existing QuranAtlas surface, border, muted text, accent, and focus tokens. Selected choices should read as active without introducing a new palette.

## Responsive differences

Mobile uses a single-column drawer flow. Wider drawers can keep the same grouping while allowing option rows to wrap naturally.

## Non-goals

This reference does not redefine reminder scheduling logic, Daily Wird progress math, or drawer navigation behavior.
