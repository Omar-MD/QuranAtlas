# QuranAtlas Product Goals

## Goal 1 — Become The User's Primary Qur'an Reader

QuranAtlas must be good enough as a reader that users choose it for normal daily reading, not only for special study sessions.

Success looks like:

- fast loading
- beautiful Arabic rendering
- reliable riwayah support
- translation and tafsir access
- offline support
- minimal visual noise
- trustworthy source provenance

## Goal 2 — Make Tadabbur Seamless

Tadabbur should not feel like a separate academic task.

The reader flow should naturally support reflection through:

- ayah tap
- subtle passage context
- one excellent prompt
- optional deeper layers
- journaling only when useful

Success looks like:

- users reflect during ordinary reading
- users do not feel overwhelmed
- reflection takes 30 seconds to 3 minutes
- the app encourages pausing without forcing it

## Goal 3 — Help Users Understand Context

Many users fail to reflect because they read isolated ayat without knowing the surrounding passage.

The app should show lightweight context:

- this passage is about X
- this ayah belongs to a section about Y
- these are the dominant themes
- this connects to related ayat

Success looks like:

- users understand where they are in the surah
- users see how ayat connect
- users stop treating every ayah as isolated

## Goal 4 — Guide Reflection Without Replacing It

The app should not do all thinking for the user.

It should ask, reveal, and guide.

Success looks like:

- the user writes or mentally forms their own insight
- the app gives prompts before long explanations
- tafsir is available after the user has paused
- AI behaves like a guide, not a mufti

## Goal 5 — Keep Scholarly Boundaries Clear

The app must preserve trust by labeling knowledge properly.

Every surfaced item should be classifiable as:

- Qur'an
- translation
- tafsir
- structured scholarly claim
- curated reflection prompt
- user reflection
- AI-assisted synthesis

Success looks like:

- users know what is source-backed
- AI outputs are grounded
- sensitive matters are guarded
- speculative reflection is not presented as tafsir

## Goal 6 — Build A Scalable Data Foundation

The pipeline must support new future surfaces without becoming tangled.

Success looks like:

- text lane remains independent
- knowledge lane supports themes/passages
- reflection lane supports prompts/actions
- search/AI lane supports retrieval/citations
- offline packs can be lane-aware
- validation catches data drift

## Goal 7 — Enable Long-Term Relationship With The Qur'an

The app should eventually remember the user's reflections and help them revisit ayat over time.

Success looks like:

- users see previous reflections
- insights resurface at meaningful times
- themes emerge across their reading
- tadabbur becomes a habit, not an event
